# Analog Clock

A simple and stylish analog clock built with HTML, CSS, and JavaScript.

## Demo

(Open `index.html` in your browser to see the clock in action.)

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Real-time analog clock with moving hour, minute, and second hands.
- Smooth rotation and accurate time display.
- Responsive design that looks good on different screen sizes.

## How to Run Locally

1. Clone the repo:  
   `git clone https://github.com/branzpajrava/branz.git`

2. Open the `index.html` file in your preferred web browser.
